# Open-source strategy

The repository is intentionally centered on a reference verifier rather than a full commercial platform.

## Public core

- verifier primitives
- rule interface
- evidence receipts
- canonical hashing
- CLI
- Node integration primitives
- examples and stable vectors

## Commercial extensions

A hosted test service, enterprise policy packs, organization-wide reporting, managed evidence retention, and professional audit workflows can live outside this repository.

The open-source project should optimize for a very short path from install to first useful security finding.
